# RBittorrent

Simple bittorrent client 

## Usage

Build project
```shell
cargo build
```

Run tests
```shell
cargo test
```

Execute
```shell
$ ./target/debug/rbittorrent -h
Usage: rbittorrent <COMMAND> <VALUE>

Arguments:
  <COMMAND>  Name of the command [possible values: decode, info]
  <VALUE>    Value to process

Options:
  -h, --help  Print help
```
